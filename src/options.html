Ticket Revision Diff Checker

GitHub GraphQL yêu cầu authentication. Nhập fine-grained Personal Access Token để đọc revision history.

Nếu không bật Remember, token chỉ được giữ trong chrome.storage.session và sẽ bị xóa khi browser/extension session kết thúc.

Quyền token

  • Public repository: fine-grained PAT có thể đọc public repository.
  • Private repository: chọn repository cần dùng và cấp Issues: Read-only.
  • Extension chỉ gọi GitHub GraphQL API để đọc Issue description và edit history.
